#  Flower Shop Website

A modern and responsive **Flower Shop Website** created using HTML and CSS.
This project provides a simple and attractive online flower-shopping interface where users can explore flowers, view products, read reviews, and contact the shop.

##  About the Project

The **Flower Shop Website** is a frontend web project designed for a flower-selling business.

The website includes different sections/pages for displaying flower products, customer reviews, contact information, and the main home page.

##  Features

*  Attractive Home Page
*  Flower Products Page
*  Customer Reviews Page
*  Contact Page
*  Clean and attractive UI
*  Responsive design
*  Flower product images
*  Simple and easy-to-understand frontend code

## 📄 Pages

The project contains the following pages:

* `index.html` — Home Page
* `Product.html` — Flower Products
* `Review.html` — Customer Reviews
* `contact.html` — Contact Page
* `styles.css` — Website styling

## 🛠️ Technologies Used

* HTML5
* CSS3

##  How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the Flower Shop website.
